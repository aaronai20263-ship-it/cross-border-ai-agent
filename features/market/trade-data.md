# 海关与贸易数据调研（市场指南补充）

本文件为进入美国市场前的官方贸易数据调研方法，用于品类机会识别、客户画像验证与关税成本评估。

## 一、官方数据来源

| 数据来源 | 说明 | 用途 |
|---------|------|------|
| **USITC DataWeb** | 美国国际贸易委员会官方数据平台，提供1989年至今的月度、季度、年度美国进出口统计 | 按贸易流向、产品分类（HS编码）自定义查询，导出Excel做竞争密度分析 |
| **Census International Trade API** | 美国人口普查局外贸司提供的API接口，覆盖2010年至今的月度商品贸易数据 | 按HS编码、港口、原产国/目的国查询进口商分布与货运量 |
| **Harmonized Tariff Schedule (2025/2026)** | 美国协调关税税则表 | 查询目标品类适用关税税率，提前测算到岸成本（Landed Cost） |
| **Census Bureau Foreign Trade Statistics** | 人口普查局外贸统计年度报告 | 获取宏观贸易趋势（2025年美国商品进口总额约3.3万亿美元，服务进口约7,500亿美元） |

## 二、数据驱动的实操步骤

1. **品类机会识别**：登录USITC DataWeb → 按HS编码（前6位）查询美国近3年进口量 → 对比主要供应国（中国、越南、墨西哥等）份额变化 → 判断市场是否饱和或有供应缺口。

2. **客户画像验证**：通过Census API按港口（如洛杉矶港、纽约港）和HS编码查询进口商记录 → 识别核心采购区域（州/城市）和采购频率 → 用于后续LinkedIn或邮件获客的地域聚焦。

3. **关税成本评估**：在HTS官网输入HS编码 → 确认适用税率（MFN或Section 301附加税） → 叠加海运费、保险费、清关费 → 算出最终到岸成本，倒推终端定价空间。

## 三、宏观基本面参考

2025年美国商品贸易逆差达1.24万亿美元（历史最高），服务贸易顺差3,395亿美元（历史最高）。这组数据反映出：
- 美国市场对实物商品的进口依赖仍在加深，**跨境卖家的基本盘稳固**；
- 高逆差行业（电子、服装、家具）竞争激烈，需靠本地化服务或差异化功能突围；
- 顺差行业（知识产权、金融、软件）可作为高附加值服务的切入参考。
