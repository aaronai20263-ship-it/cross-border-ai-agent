# 玉石 AI 智能顾问 Web MVP

## 第一性原理

用户真正需要的不是“聊天”，而是降低购买玉石时的信息不对称与判断风险。

因此产品闭环是：

用户需求 → 必要信息采集 → 图片/文字初步分析 → 风险解释 → 购买建议 → 预算与意向识别 → 人工咨询 → Lead

## 当前阶段

这是前端可运行原型。聊天、图片选择和线索表单使用浏览器端状态/模拟逻辑，尚未连接真实 LLM、视觉模型或数据库。

## 下一阶段

1. FastAPI API Layer
2. 多模态 AI Agent
3. 玉石知识库
4. Lead 数据库
5. Admin Dashboard
6. 真实图片上传与存储
7. 测试与部署

## 安全边界

AI 只提供基于输入信息的初步分析，不确认真伪、天然/处理状态、实验室检测结果或升值潜力，不替代专业鉴定证书。
